# Z-Tech Website Project Context

## Purpose

Z-Tech presents a Persian-first consultancy that discovers valuable AI opportunities, builds solutions around real business processes, integrates them with existing systems, and helps embed them into daily operations.

## Direction

- Editorial, confident, restrained, and typography-led; avoid generic AI/SaaS aesthetics.
- RTL by default with Persian content and deliberately selected Persian typography.
- Prioritize whitespace, hierarchy, composition, and responsive behavior over decoration.
- Use refined, responsive interaction only where it improves understanding and control.

## Technical priorities

- Next.js with React Server Components by default and minimal Client Components.
- Minimal dependencies and client JavaScript.
- Intentional mobile design, logical RTL CSS, optimized fonts/images, and stable layouts.

## Quality priorities

- SEO: semantic structure, strong metadata, crawlable Persian content, canonical URLs, and verified structured data.
- Accessibility: keyboard access, visible focus, semantic HTML, contrast, text scaling, useful alternatives, and reduced-motion support.
- Performance: fast rendering, low layout shift, lean assets, and measured client-side behavior.

## Sources of truth

- `docs/design-system.md` — brand and visual system.
- `docs/apple-design-system.md` — interaction quality, motion, refinement, and polish reference.
- `docs/content-structure.md` — approved content and information architecture.

## Constraints

Never invent company facts, customers, testimonials, statistics, results, or claims. Preserve source documents unless an explicit content change is approved. Do not trade accessibility, SEO, or performance for visual effects.
